CLAUDE.md の読み込み規則に従い、docs/PROGRESS.md の「次に行う1ステップ」から再開してください。

読む範囲は次の順で、必要な部分に絞ってください。

1. `docs/PROGRESS.md`：現在地、次の1ステップ、ブロッカー、直近の結果
2. `git status --short`：既存の変更を確認し、他の作業を上書きしない
3. 現在の `docs/milestones/Mx.md`：基本情報・スコープと、現在のサイクルの目的、受け入れ条件、異常系・学習確認
4. 今回の作業に関係する実装とテスト

最初の説明は「現在のマイルストーン・サイクル／完了済みのこと／今回の1ステップ／理由／確認方法」に絞ってください。全体計画は再掲しないでください。

次に行う1ステップについて、目的、理由、対象ファイル、変更内容、期待結果、確認方法を先に説明し、承認済みの範囲で進めてください。
今回不要な文書の全文読み込みや、機能・ライブラリの追加は避けてください。
