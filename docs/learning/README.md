# 学習記録の運用

このプロジェクトで扱う技術・実装について、質問から得た知識と、各ステップの実装・確認から得た知識を同じ学習記録に残します。目的は、過去に何を学び、何に疑問を感じたかを振り返れるようにすることです。
学習の詳しい経緯の正本は `docs/learning/Mx.md` です。記録ファイルはマイルストーンごとに分け、開始したものだけを作成します。

現在の記録: [M0の学習記録](M0.md)

## 1. 他の文書との役割分担

| 文書 | 記録すること |
|---|---|
| `docs/learning/Mx.md` | ステップの学習目標、取り組み、質問・回答、理解の確認、残る疑問、後日の振り返り |
| `docs/milestones/Mx.md` | サイクル全体の学習目的・受け入れ条件・完了判定。学習結果は短い要約と記録へのリンク |
| `docs/PROGRESS.md` | 現在地、次の作業、直近の結果。未理解事項は短い見出しと学習記録へのリンク |

同じ学習内容を複数の文書へ全文転記しません。既存の作業履歴は当時の記録として残し、以後の詳しい学習経緯は学習記録で更新します。

## 2. 記録する単位とタイミング

- 記録対象は、技術の概念、コードやコマンドの役割、処理の流れ、実装理由、エラーの原因、テストや動作確認から得た学びと、それらに関する疑問とする
- 学習の進め方、記録先・書式、日程、作業依頼・承認、単なる進捗確認など、プロジェクト運営についてのやり取りは記録対象外とする。「学習記録を残したい」「どのファイルにまとめるか」という相談や、この記録ルール自体の相談も学習項目として残さない
- 1つの発言に技術的な疑問と運営上の依頼が混在する場合は、技術的な学びに関係する部分だけを記録する。運営上の決定を文書へ反映する必要がある場合は、承認された範囲で該当する運用文書を更新し、学習記録への転記はしない
- 記録対象に当たる1つのステップ、または独立した疑問を1件とする。ステップ中に出た関連質問は、そのステップの記録に含める
- 質問のないステップも、技術・実装について学びがある場合は記録する。作業中の疑問に加え、コードを追ったこと、試したこと、その結果を残す
- 記録IDは `L-M0-001` のように、マイルストーンごとの連番にする。一度付けたIDは変えない
- ファイル冒頭に、ID・日付・サイクル／ステップ・テーマ・理解の確認状況の目次を置く。見出しを `## L-M0-001` とし、`#l-m0-001` で参照する
- ステップ開始時に学ぶことを提示し、区切りまたはセッション終了時に、実際の取り組みと理解の確認結果を整理する。独立した質問は、回答した区切りで整理する
- 記録・追記も [AGENTS.mdの承認ルール](../../AGENTS.md) の対象とする。対象ファイルと記録内容を提示し、承認済みの範囲で反映する。記録の仕組みの採用だけを、今後すべての記録への包括的な承認とは扱わない

## 3. 事実と理解の扱い

- 質問は本人の原文を残す。回答は要約か原文の抜粋かを明記し、理解を助けた具体例も残す
- 過去の要約しか確認できない場合は「原文未確認」と記載する。質問や当時の考えを推測して原文として補わない
- 「質問なし」と「過去の質問の有無・原文を確認できない」を区別する
- 「作業が成功した」「説明を受けた」「本人が説明できた」を分ける。本人の説明や試行結果がなければ、理解の確認は「未確認」とする
- 当時の記録から整理する場合は、出来事の日付と記録日を分け、参照元を記載する。今回再検証した結果と混同しない
- 分からないことが残っても記録して学習を続ける。理解確認の回答がないことを理由に、承認済みの作業を止めない

## 4. 1件分の書式

以下を現在の `Mx.md` に追加し、IDを採番します。各項目は短文で構いません。

```markdown
## L-M0-001

- 日付:
- 記録日: 過去の出来事を整理するときに記載
- サイクル／ステップ:
- テーマ:
- きっかけ: 実装・コード確認・テスト・質問など（複数可）

### 学ぶこと・確かめたいこと

### 当初の理解・疑問

### 取り組んだこと

### 質問と回答

- 質問（原文／原文未確認／質問なし）:
- 回答（要約／原文の抜粋）と具体例:

### 得られた知識・気づき

### 理解の確認

- 確認状況:
- 本人の説明・操作・確認結果と、その参照元:

### 残る疑問

### 参照

関連コード、会話を特定できる情報、過去の学習記録など。

### 後日の振り返り

日付・見直したこと・説明できたこと・残る疑問を追記する。
```

## 5. 振り返りと再登場するテーマ

週末に目次から1〜3件選び、回答を見ずに説明してみます。結果は元の記録の「後日の振り返り」へ、日付付きで追記します。
記録を読んで、当時の疑問、説明や試行、現在の理解を追えるかも確認します。

別のステップやマイルストーンで同じテーマを学び直した場合は、新しい記録から以前の記録へリンクします。
当初の疑問や回答は残し、回答の訂正も日付付きで追記します。マイルストーン完了時は、ここにある記録を基に、マイルストーン文書へ短い振り返りと参照リンクを残します。
